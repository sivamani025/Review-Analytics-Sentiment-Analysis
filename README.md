# Review Analytics & Sentiment Analysis

## Overview

This project focuses on analyzing customer reviews and performing sentiment classification using Natural Language Processing (NLP) and Machine Learning techniques.

The goal is to transform raw customer reviews into meaningful insights by applying text preprocessing, exploratory data analysis, feature engineering, and machine learning models.

---

## Project Objectives

* Analyze customer review data
* Perform text preprocessing and cleaning
* Explore review patterns and distributions
* Generate sentiment labels from ratings
* Convert text into numerical features using TF-IDF
* Train and evaluate machine learning models
* Compare multiple classification approaches

---

## Dataset

The project uses a customer review dataset containing:

* Review Text
* Ratings
* Product Information
* Review Metadata

### Sentiment Mapping

| Rating | Sentiment |
| ------ | --------- |
| 4 - 5  | Positive  |
| 3      | Neutral   |
| 1 - 2  | Negative  |
